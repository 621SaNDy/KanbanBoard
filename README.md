## Installation
After cloning the repository to your machine, ensure you have Docker installed and running, and launch the following command in the project root:
```bash
docker compose up
```
This will launch the database, server and client, and setup the app with starter data. If the configuration hasn't been altered, the frontend will be available at <http://localhost:8080>.
